# 耳畔使用说明

适用：**code85 / 0.3.50-minimax-chunks-test**，保留完整 code79 功能。耳畔免费开源，聊天和语音服务自行配置。

## 声音情绪识别（code80）

首页「语音通话 → 通话设置」开启「传递情绪线索」。Qwen ASR新增独立识别选项，一次返回文字和七类情绪；火山读取原生情绪，百炼Paraformer 8k路线实际转换采样率以读取三类情感。普通paraformer-realtime-v2不支持情绪。时间戳与停顿仍单独开关，缺少元信息时只发原文。

保留模思、MiniMax、Audio API兼容或Token Plan识别时，可在连接配置的「情绪补充（选用）」填写使用者自己的普通百炼Key并主动开启：同一段录音在主识别成功且缺情绪时最多额外上传一次，只取情绪、保留原转写；按百炼API计费，可能多等几秒。新补充开关默认关闭，原备注开关开启不会自动增加付费请求。Token Plan套餐Key不能替代普通Key。完整配置与验证范围见源码《声音情绪识别.md》。

关麦取消或失效补充分析，已接收的原文字按原流程保留；挂断/切窗/打断不补发旧结果。补充分析失败、超时或配置未就绪时只发主转写。改动不需要更换O插件。
## Fish Audio 官方语音合成（code79）

「连接配置」→「语音合成」选择 **Fish Audio 官方**。地址自动填入 `https://api.fish.audio/v1`，填写 Fish API Key、选择模型，再粘贴声音详情里的音色 ID（reference_id）。保存声音方案后可检查连接、只听回复或开始通话。识别配置沿用原来的服务，O 插件不用换。

默认模型 `s2.1-pro-free`，也可从菜单选择 S2.1 Pro、S2 Pro、S1、Drama 3。Free 模型额度和开放时间以平台政策为准，其他模型消耗 API 额度；失败不自动换模型。模型名和音色 ID 是两项，声音名称、网页地址不能代替音色 ID。

回复分段提交，接收 PCM16 单声道 44100 Hz 音频并陆续播放，复用原字幕、播放和打断流程。详细配置见源码的《FISH-AUDIO-接入说明.md》。本版尚待真实 Fish 账户与手机试听。
## code78：情绪与停顿线索开关

首页选择「语音通话」，在「通话设置」分别开启「传递情绪线索」和「传递停顿信息」。默认关闭，点击自动保存，结束通话后可调整，切音色保留选择。

只附加识别服务实际返回的受支持标签/时间信息，没有信息时照常发原文。当前普通百炼接法解析这些字段，是否返回取决于识别模型；其他接法目前只取文字，开关旁会提示暂不生效。不是完整音频理解，不新增模型分析或识别请求，也不改变收音、断句、打断和朗读。

发送前确认仍显示原转写；原样发送会附加勾选的备注，改字后舍弃旧音频备注。只听回复不开麦，不使用这两个开关。日志中增加两项开关状态。

## 语音诊断与识别恢复（code77起）

- 首页「通话设置」右上角「日志」→「导出日志」，选择手机保存位置，得到一个可发送的文本文件。
- 出错后尽快导出，不要先强制关闭应用。日志只保留本次应用进程的最近事件及失败摘要，不持久录音，不记录聊天正文、密钥或完整服务地址。
- HTTP 错误尽量给出服务错误码、请求编号和可识别的原因类别；服务端未返回这些字段时只保留状态码。未知原始报错正文不会直接导出。
- HTTP 识别的暂时网络错误及部分服务忙碌错误最多重试一次，每次最多30秒；400、鉴权错误和要求长时间等待的限流不自动重试。O消息和合成播放不会自动重发。
- 单句识别失败会说明“这句未发送，继续聆听”，重新说一句即可。连续失败请导出日志核对配置及服务状态。
- 本次只更新APK；已经正常工作的Operit语音插件不需要因本补丁重装。以下旧版本升级说明保留供历史版本参考。

## 安装与连接 Operit

1. 结束正在进行的通话或只听回复，安装 APK。旧用户覆盖同签名版本，保留设置；不用卸载或清除数据。
2. 在 Operit 内先发一句文字，确认所选聊天能正常回复。
3. 打开 Operit「工具 → 包管理 → ＋」，导入 `phone10-mobile-voice.js` 并启用。这里使用包管理，不是导入 .toolpkg 的插件页。
4. 运行一次 `setup`，确认返回 `SETUP_READY`。它创建或更新原语音、取消工作流；`receive` 由工作流触发，不需要手动运行。
5. 耳畔「连接配置」中选择聊天窗口，分别填写识别和合成服务、声音 ID，保存并使用。
6. 回首页点击「开始通话」，按需允许麦克风、通知和悬浮窗权限。只想听回复时选择「只听回复」。

### 升级时是否要更新插件

- code57 及更早版：同时更新 APK 和随包 JS，并运行 setup。
- 已使用 code58 或之后配套 JS：不必重复更新，本次插件与 code58 一致。
- 不确定插件版本：使用随包 JS。先保留旧文件；若 Operit 不支持覆盖同名包，在包管理移除旧 phone10_mobile_voice 条目，再导入同名 JS、启用并运行 setup。沿用原工作流，不另建重复工作流。

## 通话与只听回复

「语音通话」将识别到的话送入所选聊天，并朗读 AI 回复。「只听回复」不开麦，读取所选 Operit 聊天的新回复并朗读，开启前的历史消息不补读。

悬浮球可开关麦；关麦只暂停输入，当前回复继续。结束语音会话后再更换聊天或声音方案。只听模式的停止播放保留监听，下一条回复仍可朗读。

发送前确认开启后，识别文字要经过确认才会发送。它能帮助检查误识别，但不是识别准确率保证。人声打断保留可选开关，效果取决于设备、外放回声和环境。

## 音色切换与群聊绑定

首页「音色切换」进入独立页面。「我的音色」可搜索名称或服务，点行切换，当前方案显示勾选；加号可添加，更多菜单可移除。每份方案保存相应连接与声音设置。结束语音后切换，下次会话使用新选择。

「群聊绑定」按聊天及角色名称保存声音：读取成员或手动填写角色名，再选已保存的声音方案。名称依赖前端提供；同一聊天里的同名角色共用绑定，角色改名后需要重新绑定。选择「跟随当前音色」可解除绑定。成员依次朗读，不同时播放多路声音；缺失方案会提示错误。

兼容的本机服务可通过「电脑上的声音」刷新目录并保存新方案。目录失败保留原设置，不会用默认声冒充指定声音。包内不附带维护者的私人音色。

## 服务与朗读方式

识别与合成可以选不同服务，密钥在手机本地加密保存。识别可选百炼、火山、MiniMax、Moss 或 Audio API 兼容。

| 合成服务 | 方式 |
| --- | --- |
| 阿里云百炼 | CosyVoice WebSocket，持续追加文字 |
| 火山引擎 / 豆包 | v3 双向流式；资源、模型、音色需匹配 |
| MiniMax | 双向流式合成 |
| 模思 Mossland | HTTP 音频流；快速响应、语气连贯、整条合成 |
| ElevenLabs | 客户端提供 v4 Turbo / Flash v2.5 流式追加，v4 / v3 分段合成 |
| Audio API 兼容 | 服务需实现 HTTP PCM 合同 |
| 本机语音 | 自建兼容 WSS 网关与声音目录 |

模型与音色是否可调用，以你的服务账号为准。「检查连接」读取聊天列表，并执行静音识别、固定短句合成；不开麦、不播放，但可能产生少量服务用量。只听模式不检查识别。

本机「首句先读」遇首个断句标点即提交。后续短句合并，约 1.5 秒时提交到已有的最后一个标点，或者累计约 100 字遇标点提交；未完成的末尾文字继续等待，回复真正结束才提交余文。单段有 600 Unicode 码点上限，极端无标点文字仍需硬分段。工具等待不当作回复结束。

Moss「语气连贯」减少独立生成次数；「整条合成」等本条回复结束再提交，等待更久，仍受服务长度和超时限制。客户端不能保证消除模型的音色漂移。

## 声音收藏与试听

首页「声音收藏」里的最近声音可直接试听，不用先收藏。支持播放、暂停、拖动进度，点另一条会停止旧试听，离开页面停止试听。

星星保存原音频，重复收藏同一来源不会新增副本。更多菜单可复制文字、导出 WAV；多段声音还能选择一句收藏。最近声音保留最近 24 条、最多 128 MB，收藏长期保留。

通话中点试听会询问是否结束当前语音，确认后再试听，不自动重新开麦。试听使用已经生成的音频，不重新合成。标记「未播完」的声音只包含实际保存下来的音频，文字可能多于音频内容。

## 字幕与后台

首页通话设置中切换「悬浮字幕」，下方「字幕设置 ›」可调整原有带框或透明样式、字号和颜色；字幕关闭时也可设置样式。

支持的分段合成路线按实际播放段落跟随。手动上翻暂停跟随，点「回到朗读」恢复。没有分段标记的路线仍显示文字；不是逐字卡拉 OK 时间轴。

按手机系统要求允许耳畔与 Operit 后台运行。长任务插件等待上限为 30 分钟，手机额外 10 秒收尾；Operit 与其他服务还有各自限制。合成失败时聊天文字继续，不自动重发任务或切付费云端。

## 问题反馈

首页「未连接」表示当前没有运行语音会话。点击开始后若失败，请记录当时提示，并查看「最近语音状态」，提供耳畔版本、Operit 版本、手机系统、服务名称和复现步骤；遮住密钥、私人地址及聊天内容。

安静时自动发文字、短促爆音或漏句需要分别排查；本次没有宣称解决这些尚未定位的反馈。可疑声音可先收藏原音频，帮助比较是否在同一位置重复出现。

本版未开放此前的气声试验和完整音频情绪理解；情绪/停顿开关仅转交识别服务实际返回的受支持字段。发布候选的自动检查与手机试听状态见随包验证说明。语音由 AI 合成。

## Token Plan 套餐接口测试版（code75）
在连接配置的百炼识别、合成两栏，分别点击「填入 Token Plan 套餐配置」，再填写套餐专属 Key。识别模型 qwen-audio-3.0-asr-flash，合成模型 qwen-audio-3.0-tts-plus，默认音色龙安陆风；地址和模型自动预填。识别为说完一段后上传，合成边生成边播放。原百炼接法继续可用；已连接 O 的人无需因此更新插件。
这是接口适配测试版，尚未用群友账号和手机实测。套餐可用模型、额度及应用使用范围以阿里云规则为准；客户端不会绕过限制或自动转按量计费。
# 电脑主动来电（code76）

电脑完成自主活动后，可以沿 O 的电脑接收插件发来文字或耳畔来电邀请。先保存原话到原聊天，再显示短时来电通知；接听才开启现有语音通话，开场原话只读一次。拒接、到期或接通失败时原话仍在 O。来电不改聊天选择、声音方案或凭据，也不会在开机后重播。

使用前：耳畔里仍选平时使用的 Sol 私聊，保留已经能正常通话的语音配置，允许耳畔通知和麦克风。电脑收件插件在 O 单独导入并点 setup；手机使用情况访问权限也授予 O。耳畔不要求使用情况权限。来电提示的实际声音、锁屏展示受手机通知设置和勿扰模式控制。
